# Published benchmark run

`20261015-145656/` contains the three saved files required to rebuild the landing page from a fresh checkout:

- `raw.jsonl`: all original attempts, deduplicated by the exporter using the runner's resume policy.
- `snapshot.json`: exact texts, prompt, scoring targets, and run provenance.
- `config.json`: model IDs, effort levels, repetitions, and request settings.

These are byte-for-byte copies of the corresponding files from `results/20261015-145656/`. Experimental runs and the carousel PDF are not included here. The generated site exposes effective responses and scored data as downloads.
